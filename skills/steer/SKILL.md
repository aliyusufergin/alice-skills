---
name: steer
description: Absorb a new idea or change of mind into a build already underway while keeping its thread. Use when the user adds or changes something after work has started.
---

Fold the change into the existing work so that a fresh agent reading the record would build the new reality. Read the spec and record, if there are any, and bring any step in progress to a safe point.

Sort the change, asking only what the sorting needs:

- **Within the intent and its scale:** add it to the route, and to `next.md` if it should come soon. Carry on.
- **Changes the intent, its scale, a commitment, "not doing" or "done means":** show the user what would change, including which finished work it affects. Ask them to confirm only if something there would surprise them. Then update the spec in their words, rewrite the remaining route, including any rework, journal why, and rewrite `next.md`.
- **A separate piece of work:** add one line to `.work/parked.md` and carry on with the current work.

Tell the user which case you chose, so they can overrule it. Building resumes once any confirmation you need has come.
